# Compra Viagem — Brand Repository

Repositório oficial da identidade visual da **Compra Viagem**.

![Assinatura principal](assets/logo/full/compra-viagem-logo-primary.svg)

## Sistema aprovado

- **Direção:** Movimento Conectado
- **Wordmark:** desenho proprietário com ponto coral único
- **Ícone compacto:** R15 — Continuidade
- **Motion completo:** R18 — Compra vira Viagem
- **Sistema consolidado:** R19
- **Componente responsivo:** R20
- **Aplicações:** direção visual 60/30/10

## Uso rápido

```html
<img
  src="assets/logo/full/compra-viagem-logo-primary.svg"
  alt="Compra Viagem"
  width="180"
/>
```

Use a assinatura completa sempre que houver **128 px ou mais**. Abaixo desse limite, use o ícone compacto R15. Consulte [`docs/logo.md`](docs/logo.md) e [`docs/motion.md`](docs/motion.md) antes de implementar.
