# Motion assets

- `full/`: narrativa completa R18 para fundos claros e escuros, estado reduzido, previews e especificação.
- `compact/`: animação breve R15 para abertura compacta.

Os SVGs são as fontes preferenciais para implementação web. MP4 e GIF são formatos de apresentação e compatibilidade. Consulte [`docs/motion.md`](../../docs/motion.md) antes do uso.
