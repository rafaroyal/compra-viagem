# Motion assets

- `full/`: narrativa completa R18 para fundos claros e escuros, estado reduzido, previews e especificação.
- `compact/`: animação breve R15 para abertura compacta.
- `splash.html`: splash responsivo usando a narrativa oficial R18 uma vez.
- `loading/`: SVG e demo do loader de rota para espera indeterminada.

O loader não substitui nem coloca o logo R18 em loop. Os SVGs são as fontes preferenciais para implementação web. MP4 e GIF são formatos de apresentação e compatibilidade. Consulte [`docs/motion.md`](../../docs/motion.md) antes do uso.
