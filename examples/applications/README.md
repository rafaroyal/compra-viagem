# Aplicações responsivas

Referências de uma homepage da Compra Viagem aplicando a identidade em contexto real de produto.

| Arquivo | Finalidade |
| --- | --- |
| `compra-viagem-desktop.png` | referência desktop em alta resolução |
| `compra-viagem-mobile.png` | referência mobile em alta resolução |
| `compra-viagem-desktop.svg` | fonte vetorial editável da referência |
| `compra-viagem-mobile.svg` | fonte vetorial editável da referência |
| `travel-home.html` | implementação responsiva navegável |

Estas telas validam direção de marca, hierarquia, fotografia e comportamento responsivo. Fluxos, preços, destinos e conteúdo são ilustrativos e precisam de validação de produto antes de implementação definitiva.
